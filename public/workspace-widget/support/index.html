Support scope

Workspace Widget is currently a 0.1.0 public release candidate. Only Windows 11 x64 is supported, and pre-certification development packages are not offered as public installers.

  • Private security advisory: vulnerabilities and sensitive material
  • After Partner Center certification: support details on the Microsoft Store listing
