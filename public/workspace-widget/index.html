Local-first

Your workspace stays on your device.

Workspace Widget has no developer-operated account, advertising, analytics, or telemetry service.

  • Layout and shortcut configuration live in per-user local app data
  • Requests are limited to health, URL, and media features you configure or invoke
  • Local projects are not uploaded and dependencies are not installed automatically
  • Security boundaries and network behavior are documented in public source
Public release candidate

The source is public. Store distribution is awaiting certification.

The public repository is currently for source review. Unsigned development packages are not distributed, and no installer is offered until a certified Microsoft Store listing is ready.
