Privacy Policy

Workspace Widget is a local-first Windows desktop launcher. It does not include developer-operated analytics, advertising, telemetry, accounts, or a remote data-collection service.

In short: configuration stays on your device. Network requests occur only for features you configure or invoke.

Data stored on the device

Workspace Widget stores its data under %LOCALAPPDATA%\WorkspaceServiceWidget. This can include layout and appearance settings, shortcut targets, arguments, working directories, health URLs, local-service settings, and media choices in state.json and state.json.previous.

The directory can also contain runtime.log and host.log diagnostic files, downloaded remote media in IconCache and MediaCache, and the WebView2 profile and cache used by an optional YouTube preview. Logs can include timestamps, local paths, configured URLs, and error details.

Workspace Widget reads an image from the clipboard only after you choose Paste image. The selected image is saved as a local PNG in IconCache.

These are ordinary local files and are not encrypted by Workspace Widget. They rely on your Windows account, file-system, and device protections.

Shortcut arguments and URLs are plain-text local configuration. Do not put passwords, access tokens, private keys, or other secrets in them.

Network requests

Workspace Widget makes network requests only for features you configure or invoke:

  • An optional health URL is polled every 30 seconds to show service availability.
  • An HTTP or HTTPS shortcut opens in your selected browser.
  • Remote image or media sources are requested from their configured hosts.
  • YouTube preview playback, when enabled, connects to YouTube's privacy-enhanced embed service through Microsoft Edge WebView2.

Your device connects directly to the selected endpoint, browser destination, media host, or YouTube/Google service. Those parties can receive ordinary connection and request information, such as IP address, user agent, requested URL, and time, and apply their own privacy policies. Workspace Widget does not proxy these requests through a developer-operated server.

You control these connections by editing or removing the relevant health, URL, or media setting, or by not enabling a YouTube preview. WebView2 permission requests are denied by the app, and downloads and pop-up windows are blocked.

Third parties, sale, and advertising

The developer does not receive personal information through Workspace Widget, sell personal information, use it for targeted advertising, or share it with a developer-operated third party. A configured endpoint, browser destination, media provider, or YouTube/Google receives request data only when you configure or invoke the corresponding feature.

Local processes

The optional local-service feature starts only a Node.js project or script you select and runs it with the signed-in user's Windows permissions. That project is separate software and can have its own network behavior and privacy practices. Workspace Widget does not upload the project to the developer and does not install project dependencies automatically.

Retention and deletion

You can inspect and back up the local data directory, edit or remove registered entries, disable configured network features, and exit the app from its tray menu. Removing an entry does not delete its original file, folder, application, or project, and does not automatically delete an already cached icon or media file.

State and recovery data persist until normal use overwrites them or you remove them. runtime.log stops growing at 4 MB. IconCache and MediaCache each enforce a 128 MB write budget and are not silently cleared by the app. Exact update, uninstall, and reinstall retention will be independently verified when a Store-signed package becomes available. This policy will be updated before general availability if observed behavior differs.

To remove all local data, exit Workspace Widget from its tray menu, back up the directory if needed, and then delete %LOCALAPPDATA%\WorkspaceServiceWidget using Windows. This permanently removes the app's state, recovery data, logs, managed caches, and WebView2 profile and cannot be undone. Review the resolved path and contents before deleting it.

Product website

This website stores only language and theme preferences in browser local storage. It does not use developer-operated analytics, advertising, or advertising cookies. The site is hosted by GitHub Pages, so GitHub can process ordinary connection information under its privacy statement.

Read the GitHub General Privacy Statement

Children

Workspace Widget is a general productivity utility and is not directed to children. It does not knowingly collect personal information from children.

Changes and contact

Material policy changes update the date and are published with release information. For privacy questions, use the public issue path on the support page without including sensitive details. Send security vulnerabilities or sensitive information only through the private security form.
